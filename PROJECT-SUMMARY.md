## 🎮 How to Use After Starting

### Add a Wrestler
1. Click "Roster" tab
2. Click "+ Add Wrestler"
3. Enter name, select show, division, status
4. Click Save

### Schedule a Match
1. Click "Matches" tab
2. Click "+ Schedule Match"
3. Select show, date, participants
4. Click Save

### Create a Championship
1. Click "Championships" tab
2. Click "+ Add Championship"
3. Enter name, show, holder
4. Click Save

### Record a Transfer
1. Click "Transfers" tab
2. Click "+ New Transfer"
3. Select wrestler and destination show
4. Click Save

## 🐛 If You Get Stuck

| Issue | Check |
|-------|-------|
| Can't find Node.js | Download from nodejs.org |
| "Cannot find module" | Run `npm install` |
| Port 5000 in use | Close other apps or change port |
| Database errors | Delete data/wwe-universe.db & restart |
| Data not showing | Refresh browser (Ctrl+F5) |
