 🎯 WHAT HAPPENS AFTER YOU START
 ─────────────────────────────────────────────────────────────────────────────

 1. npm install
    → Downloads Express, SQLite, and dependencies
    → Creates node_modules folder

 2. npm start
    → Starts Express web server on port 5000
    → Creates SQLite database in data/ folder
    → Shows: "🎭 WWE Universe Mode Manager running on http://localhost:5000"

 3. Browser opens to http://localhost:5000
    → Professional web interface loads
    → Database tables automatically created

 4. You're ready to use!
    → Start adding wrestlers
    → Schedule matches
    → Create championships
    → Record transfers

 🐛 COMMON ISSUES & SOLUTIONS
 ─────────────────────────────────────────────────────────────────────────────

 Issue                      Solution
 ────────────────────────   ──────────────────────────────────
 "Node.js not found"        Download from nodejs.org
 "Cannot find module"       Run: npm install again
 "Port 5000 already in use" Close other apps or change port
 "File not found"           Check file placement with COPY-INSTRUCTIONS.txt
 "Data not showing"         Refresh page (Ctrl+F5)
 "Server won't start"       Check terminal for error message
 "Database errors"          Delete data/wwe-universe.db, restart
