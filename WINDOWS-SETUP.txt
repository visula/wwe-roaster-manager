🔧 MANUAL SETUP (If Automated Doesn't Work)
═══════════════════════════════════════════════════════════════════════════════

Step 1: Open File Explorer
──────────────────────────
✓ Create folder: C:\Users\[YourUsername]\wwe-universe-mode
✓ Inside it, create two folders:
  - server
  - public


Step 2: Copy Files
──────────────────
✓ Copy: package.json             → wwe-universe-mode\
✓ Copy: server-index.js          → server\      (RENAME TO: index.js)
✓ Copy: db.js                    → server\      (KEEP NAME)
✓ Copy: public-index.html        → public\      (RENAME TO: index.html)


Step 3: Install Dependencies
─────────────────────────────
✓ Open Command Prompt (Windows Key → type "cmd" → Enter)
✓ Navigate to project: cd wwe-universe-mode
✓ Type: npm install
✓ Wait for completion (may take 2-3 minutes)


Step 4: Start Application
──────────────────────────
✓ In same Command Prompt, type: npm start
✓ Wait for message: "🎭 WWE Universe Mode Manager running on http://localhost:5000"
✓ Open browser → http://localhost:5000

✅ PREREQUISITES
═══════════════════════════════════════════════════════════════════════════════

Before starting, verify:

1. Node.js Installed
   ─────────────────
   Open Command Prompt and type: node --version
   
   You should see: v14.0.0 or higher
   
   If not: Download from https://nodejs.org


2. All Files Present
   ──────────────────
   In F:\Work\Fun-Projects\ you should have:
   ✓ package.json
   ✓ server-index.js
   ✓ db.js
   ✓ public-index.html
   ✓ setup-windows.bat
   ✓ start-app.bat
   
   (Plus documentation files)


3. Correct Folder Location
   ──────────────────────────
   Create: C:\Users\[YourUsername]\wwe-universe-mode\
   
   Not: C:\WWE or C:\wwe-manager
   
   (Your Windows username can be found in File Explorer)

📁 FOLDER STRUCTURE (What It Should Look Like)
═══════════════════════════════════════════════════════════════════════════════

CORRECT ✓
─────────
C:\Users\YourName\wwe-universe-mode\
├── package.json
├── server\
│   ├── index.js              (from server-index.js)
│   └── db.js
├── public\
│   └── index.html            (from public-index.html)
└── node_modules\             (auto-created)


INCORRECT ✗ (Common Mistakes)
──────────────
C:\WWE\                       → WRONG - Wrong folder location
C:\wwe\                       → WRONG - Lowercase
C:\Users\YourName\WWE\        → WRONG - Wrong name
server\index.js.txt           → WRONG - Text file, not renamed

🚨 IF setup-windows.bat FAILS
═══════════════════════════════════════════════════════════════════════════════

Error: "Node.js not installed"
────────────────────────────
✓ Download Node.js from: https://nodejs.org
✓ Run the installer
✓ Restart computer
✓ Try setup again


Error: "Cannot find files"
──────────────────────────
✓ Make sure all 4 files are copied
✓ Check folder structure matches diagram above
✓ File names must be exact:
  - index.js (not Index.js or index.js.txt)
  - index.html (not Index.html)


Error: "npm not found"
──────────────────────
✓ Node.js installation failed
✓ Uninstall Node.js completely
✓ Download fresh from nodejs.org
✓ Install and restart computer

🔄 RENAME FILES (Critical Step!)
═══════════════════════════════════════════════════════════════════════════════

MUST RENAME These Files:

1. server-index.js  →  index.js
   ──────────────────────────────
   ✓ Right-click on server-index.js
   ✓ Click "Rename"
   ✓ Delete "server-" part
   ✓ Save as: index.js
   ✓ Place in: server\ folder


2. public-index.html  →  index.html
   ────────────────────────────────
   ✓ Right-click on public-index.html
   ✓ Click "Rename"
   ✓ Delete "public-" part
   ✓ Save as: index.html
   ✓ Place in: public\ folder


DO NOT RENAME:
   ✓ package.json (keep as-is)
   ✓ db.js (keep as-is)

💾 WHAT npm install DOES
═══════════════════════════════════════════════════════════════════════════════
