⚡ QUICK START STEPS
────────────────────

FOR WINDOWS:
1. Organize files in correct folders (see QUICK-REFERENCE.md)
2. Double-click: setup-windows.bat
3. When complete, double-click: start-app.bat
4. Open browser: http://localhost:5000

FOR MAC/LINUX:
1. mkdir wwe-universe-mode && cd wwe-universe-mode
2. mkdir server public
3. Copy 4 files to correct locations
4. npm install
5. npm start
6. Open browser: http://localhost:5000

🚨 COMMON MISTAKES TO AVOID
────────────────────────────

1. Create folders: server/, public/, data/
2. Copy & rename files correctly
3. Run npm install
4. Run npm start
